# Mission: Own the architecture of this codebase

## Why
Use AI agents to build this project while staying able to explain its architecture, question important decisions, and judge the evidence that it works. Learn a repeatable way to do that without reading every line.

## Success looks like
- Trace one question from the browser through search to the answer.
- Explain one important design decision and its consequence.
- Describe what an existing test proves and what remains uncertain.

## Constraints
- Use small diagrams, short interactive lessons, and plain English.
- Let the learner choose where to explore deeper; keep each lesson focused.
- Ground explanations in the current source. All activity data remains fictional.

## Out of scope
- A line-by-line Rust course or changes to application behavior.
- Claims of mastery before the learner demonstrates understanding.
