De code in vijf minuten

Rust zoekt lokaal in vijf verzonnen activiteiten. Codex gebruikt gevonden passages om via een externe modeldienst één antwoord te maken.

Begin bij de systeemkaart. Volg daarna één vraag; ieder onderdeel verwijst naar de echte code.

De grens: MiniLM en de documentvectoren zijn lokaal. De vraag en opgehaalde tekst gaan via Codex naar OpenAI. Er is geen database en dit is geen toestemming voor echte interne data.

Volg één vraag

“Waar en wanneer kan ik tuinieren?”

Een eerste zoekactie kan de tijd vinden. Codex kan daarna gerichter de locatie zoeken. De gebruiker krijgt één antwoord; het aantal zoekacties ligt niet vooraf vast.

Twee processen, dezelfde zoekcode

Webstart laadt bronnen/index voor metadata. De MCP-child laadt bij zijn eerste zoekcall een eigen Index. Geen gedeeld Index-object of aparte vectorservice. Modelgewichten staan op schijf in .model-cache/; vectoren en runhistorie staan in RAM.

Begrensd en controleerbaar

Eén actieve modelrun, maximaal vier zoekcalls, standaard drie passages per call en 120 seconden timeout. De zoekresultaten kunnen relevante informatie missen. Letterlijke citaatcontrole bewijst herkomst, geen volledige feitelijke juistheid.
