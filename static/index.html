What runs locally?

Rust splits the source at its six section headings, embeds each section once in memory, then embeds your question and ranks the sections by cosine similarity. The CLI and this page use the same search function.

Model: . The model files download once; no API key is needed. The expected evidence is kept outside the embedding inputs and search response.

With six passages, a closest result will always exist. This experiment has no calibrated “no match” threshold, and five questions do not prove retrieval quality. Transport and current availability must not be inferred from a similarity score.

This is an independent learning experiment, not an internal COA plan. All source data is invented. Participation is voluntary; an employee discusses options with the resident. The demo writes no records, sends no messages and registers nobody.
