# Decisions for the one-document experiment

Scope: one fictional activity document, five fixed questions, Rust retrieval and human review. No database, resident accounts, automatic eligibility decisions or larger benchmark.

- Keep the quantized multilingual MiniLM model and fastembed 7.1.2 chosen for the first slice. Query and document embeddings share one model instance. No prefixes; section inputs are heading, newline and exact section text. Maximum input length is explicitly 512 tokens; 384 dimensions are validated. No tuning to the five expected answers.
- Read document ID and source date from the source itself. Reject missing/duplicate metadata, invalid calendar dates, duplicate/empty section IDs, empty headings or empty evidence. IDs and text in results come from those parsed sections.
- Keep document vectors in memory, built once at process start. No persistent vector index can become incompatible. The manifest records source/vector hashes, model, dimensions, SDK, encoding/chunk/filter settings, platform and fixed `as_of`. Model downloads use the provider's mutable repository revision; the vector hash detects changed document embeddings, but this does not promise bit-identical output across platforms or future model downloads. Keep the cache for local replay.
- Source date is **2026-10-20**. The availability observation in the text is **2026-09-01**. The reference date is **2026-10-20**. These are distinct: source freshness never establishes current places. Transport is absent from the source, so its status remains unknown. Retrieval does not infer these facts or generate an answer.
- Default top-k is 3, configurable from 1 through 6. Ties use section ID. Dense scores are cosine similarity; the baseline uses Jaccard overlap of lowercase alphanumeric tokens, without tuned stopwords. Neither method has a no-match threshold.
- Five-question evaluation is a transparent learning record, not a held-out benchmark or quality gate. It counts distinct required source sections, keeps unknown criteria separate and assesses no generated claims. Gold is read by the CLI evaluator and explicit human-review endpoint, never indexed or returned by search.
- Deterministic CI checks run formatting, clippy, tests and build without loading/downloading an embedding model. Dependency/native runtime downloads may still occur during compilation. The live five-question evaluation is a separate local command.

Sources: [fastembed 7.1.2](https://github.com/anush008/fastembed-rs/releases/tag/v7.1.2), published **19 October 2026**; [checkout 7.0.1](https://github.com/actions/checkout/releases/tag/v7.0.1), published **20 July 2026**. CI pins the checkout action commit.
